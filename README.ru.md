# NotchTint

[English](README.md) | **Русский**

Растворяет вырез MacBook в приложении. Когда активное окно развёрнуто на весь
экран, NotchTint закрашивает пустую область строки меню вокруг выреза точными
цветами верхнего края приложения — больше никакой чёрной пустоты вокруг камеры.

![demo](demo.gif)

## Возможности

- **Точные цвета** — берутся реальные пиксели верхнего края окна. Левая и
  правая половины считываются отдельно, так что у приложения с тёмной боковой
  панелью будут оба цвета, плавно перетекающие друг в друга градиентом посередине
- **Медиана, а не среднее** — кнопки окна и панели инструментов не искажают цвет
- **Анимация сканирования** — пока новое окно считывается, вокруг выреза
  «дышит» ореол, а затем цвет растекается из-под него
- **Ручной выбор** — для любого приложения можно задать цвет системной пипеткой
- **Не мешает** — исчезает, когда курсор заходит в зону строки меню, поэтому
  меню никогда не перекрываются; скрывается на рабочем столе и в Mission Control
- **Полоса на каждый Space** — у каждого полноэкранного Space своя полоса,
  поэтому она уезжает вместе с приложением при переключении между Spaces
- **Кэширование** — цвет считывается один раз на окно и переиспользуется;
  повторно — при изменении размера и смене светлой/тёмной темы. Никакой
  постоянной записи экрана
- **Один Swift-файл, без зависимостей**

## Установка

Нужны Apple Silicon и macOS 14 или новее.

```sh
brew install --cask tedytag/tap/notchtint
```

Или скачайте `NotchTint.zip` из [Releases](https://github.com/tedytag/notchtint/releases)
и перенесите приложение в `/Applications`.

**Первый запуск.** NotchTint не нотаризован (нет платного аккаунта Apple
Developer), поэтому macOS его блокирует. Разрешите запуск в *Системные
настройки → Конфиденциальность и безопасность → Всё равно открыть* или снимите
флаг карантина:

```sh
xattr -dr com.apple.quarantine /Applications/NotchTint.app
```

Затем macOS запросит разрешение на **Запись экрана** — оно нужно, чтобы
считывать пиксели края окна. Выдайте его в *Системные настройки →
Конфиденциальность и безопасность → Запись экрана* и перезапустите приложение.

## Меню

Всё управляется из значка в строке меню.

| Пункт | Что делает |
|---|---|
| Enabled | главный переключатель |
| Exclude / Include *App* | не закрашивать для активного приложения или снова включить |
| Pick Color for *App*… | системная пипетка; цвет заменяет автоматическое считывание для этого приложения |
| Reset Color for *App* | сбросить выбранный цвет и вернуться к считыванию |
| Refresh Color | заново считать цвет текущего окна (например, сайт сменил тему); перед заменой выбранного вручную цвета спросит подтверждение |
| Settings | окно с теми же переключателями, списком исключённых приложений и выбранными цветами |
| Start at Login | запускать NotchTint при входе в систему |

## Как это работает

Окно без рамки, пропускающее клики, лежит поверх строки меню на каждом
полноэкранном Space. Лёгкая проверка геометрии (без записи экрана) решает,
когда его показывать. Цвета считываются через ScreenCaptureKit только когда
появляется новое окно или меняется его размер, поэтому индикатор записи экрана
появляется только в этот момент, а не постоянно.

## Ограничения

- При считывании цвета macOS ненадолго показывает индикатор записи экрана.
  Это системная защита приватности: ни один публичный API не читает пиксели
  чужого приложения без неё. (С выбранным вручную цветом индикатора нет вовсе.)
- Цвета обновляются при изменении окна, а не постоянно во время прокрутки —
  если приложение перерисовало панель инструментов, используйте Refresh Color.

## Сборка из исходников

```sh
git clone https://github.com/tedytag/notchtint.git
cd notchtint
make app
open NotchTint.app
```

- `make build && ./notchtint` запускает приложение как обычный бинарник —
  удобно для разработки, но разрешение на запись экрана сбрасывается при каждой
  пересборке. Самоподписанный сертификат для подписи кода с именем
  «NotchTint Signing» в связке ключей сохраняет разрешение между пересборками
  через `make app` (см. Makefile).
- Чтобы сменить иконку приложения, положите `icon.png` размером 1024×1024 в
  корень репозитория и выполните `make icon && make app`.
